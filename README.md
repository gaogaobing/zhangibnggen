# 幸运商城（H5 幸运抽奖商城）

一个零依赖的 H5「幸运商城」抽奖电商平台，包含前端商城 + 管理后台。用户参与商品份额购买，满额自动开奖；支持会员充值余额、指定收款账户（微信 / 支付宝 / 银行卡）收款码上传。

## 技术栈

- 后端：Node.js 内置 `http` 模块（**零 npm 依赖**）
- 存储：JSON 文件（`data/db.json`，开箱即用，无需数据库）
- 前端：原生 HTML + CSS + JS（移动端 H5）
- 后台：单页管理后台（`admin/index.html`）

## 功能概览

### 前端（H5）
- 首页：轮播图 + 抽奖商品列表（图片 / 名称 / 总份数 / 已售 / 单价 / 剩余 / 状态）
- 商品详情：商品信息、参与记录、往期中奖、立即参与
- 参与购买：支付后获得随机夺宝码，满额自动开奖
- 开奖页：自动开奖与中奖公示
- 我的：参与记录、夺宝码、中奖记录、收货地址、会员余额、账单流水
- 充值中心：充值套餐 / 自定义金额 → 选择收款方式 → 查看商户收款码 → 提交后由后台「确认到账」计入余额

### 管理后台（`/admin`，密码 `admin888`）
- 首页管理：轮播图与基础设置
- 商品管理：CRUD（设定总份数 + 总金额自动算单价）、上/下架、手动开奖
- 订单管理、开奖管理（含物流）、用户管理（余额调整）
- 中奖记录、数据统计
- 收款账户：配置微信 / 支付宝 / 银行卡收款码（**直接上传图片**）与账号
- 余额充值：充值订单列表、确认到账

## 快速开始

```bash
# 需要 Node.js 14+
node server.js
```

启动后访问：
- 商城首页：http://localhost:3000/
- 管理后台：http://localhost:3000/admin （密码 `admin888`）

### 初始化演示数据

```bash
node seed-demo.js
```

生成演示商品、用户、充值套餐、轮播图与示例订单/中奖记录。**注意**：该脚本会重置业务数据，但保留已配置的收款账户。

```
├── public/              # H5 前端
│   ├── index.html       # 首页
│   ├── detail.html      # 商品详情
│   ├── pay.html         # 参与购买
│   ├── draw.html        # 开奖页
│   ├── mine.html        # 我的
│   ├── recharge.html    # 充值中心
│   ├── css/style.css
│   └── js/common.js

```

## 部署说明

- 运行时业务数据（`data/`）与上传文件（`uploads/`）已通过 `.gitignore` 排除，仓库仅含代码。
- 部署到新环境后运行 `node seed-demo.js` 生成演示数据，或直接按需通过后台录入。
- 生产环境建议在反向代理（Nginx / Caddy）后运行，并妥善保管后台密钥。

## 安全提示

后台默认密钥为 `admin888`，上线前请务必修改（见 `server.js` 中 `x-admin-key` 校验逻辑）。
